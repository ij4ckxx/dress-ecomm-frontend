# Category & Search PLP Architectural Guide

## 1. Overview & Objectives
This document provides a comprehensive technical reference for the modern **Category PLP (Product Listing Page)**, **Search Discovery Engine**, and **Product Recommendation Carousel** built for the luxury women's fashion ecommerce platform.

All implementations strictly adhere to:
- **Zero Static/Hardcoded Dummy Content**: Every badge, price, color swatch, brand, review rating, and category is dynamically sourced from the PostgreSQL/Prisma backend.
- **SSR-First Performance & Next.js App Router Standards**: Built with Server Components, React 19 `useTransition` for optimistic UI, and Next.js Server Actions.
- **GSAP Animation Standards**: Micro-interactions, heart pop physics, and image crossfades.
- **Full Filter Synchronization**: Clean URL query state management (`minPrice`, `maxPrice`, `brand`, `color`, `size`, `rating`, `inStock`, `sort`, `page`).

## 3. Key Enhancements & Implementations

### 3.1 Product Card (`CategoryProductCard.tsx`)
- **No Static Dummy Content**: Completely stripped static strings (`"Free Delivery"`, `"Verified"`, `"Compare"`, `"Authentic Weave"`, and fallback ratings `4.9 (12)`).
- **Dynamic Color Swatches**: Real database color variants with visual hex dots, active selection rings, and `+N` excess counts.
- **Floating Wishlist Heart**: Positioned over the lower right of the primary visual with GSAP spring bounce (`back.out(2.5)`).
- **Pricing & Discounts**: Accurate INR formatting (`₹`), strikethrough original price, and dynamic `Save X%` badge.
- **Genuine Ratings**: Stars and review counts only render when genuine data is present from the backend.
- **Adaptive Action CTA**:
  - `Select Options`: For products with variants or modifiers, routes smoothly to `/product/[slug]`.
  - `Add to Bag`: For standalone simple items, dispatches `addToCartAction` with inline loading spinner and success confirmation.

### 3.2 Filter Sidebar (`CategoryFilterSidebar.tsx`)
- **Dedicated Clear Buttons**: Each filter section header (`Price`, `Brand`, `Color`, `Size`, `Customer Rating`, `Availability`) features an individual `Clear` button that resets only its respective query keys.
- **Global Reset**: Prominent "Clear All Filters" button in both the desktop sidebar header and the mobile drawer footer.
- **Category Folder Directory**: Expandable tree structure allowing users to drill into parent and subcategories directly from the sidebar.
- **Multi-Select Filters**: Comma-separated query parameters with instant URL synchronization and automatic `page=1` reset.

### 3.3 Universal Pagination (`Pagination.tsx`)
- **Controls**: Includes `« First`, `‹ Prev`, dynamic sliding page window with ellipses, `Next ›`, and `Last »`.
- **Accessibility & UX**: Proper ARIA labels (`aria-label="Go to first page"`, `aria-current="page"`), touch targets ($40\times 40\text{ px}$), and item summary (`Showing 1 - 24 of 45 designs`).

### 3.4 Search Page & Autocomplete (`HeaderSearch.tsx` & `/search/page.tsx`)
- **Dual Presentation**:
  - Top section: **Matching Categories** display with thumbnails and product counts.
  - Main grid: **Matching Products** displaying all items found (e.g. 45 products for `"ca"`).
- **Backend Query Resolution**: Resolved key collision where backend treated `q` as a product attribute. Both backend services (`product.service.js` and `category.service.js`) and frontend API clients now seamlessly support both `search` and `q`.
- **Loading Skeletons**: Interactive shimmer feedback in the search dropdown during autocomplete queries and full skeleton grids during page transitions.

### 3.5 "You May Also Adore" Carousel (`ProductCarousel.tsx`)
- **Shared Architecture**: Usable across Category PLP (`/category/[slug]`), Search PLP (`/search`), and PDP (`/product/[slug]`).
- **Touch & Drag Snap Scrolling**: Native CSS scroll-snap (`snap-x snap-mandatory`) with hardware-accelerated momentum.
- **Navigation Controls**: Disabled-state circular navigation buttons with hover fill transitions and live scroll progress indicator.
- **Self-Fetching Fallback**: When products are not explicitly passed via props, automatically fetches curated recommendations (`bestselling`) scoped to the active category.
