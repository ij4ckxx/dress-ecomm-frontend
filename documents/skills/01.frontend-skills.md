# Premium Fashion UI Design Standards

## Instructions & Rules

### 1. Design Philosophy

- Design like a senior UI/UX designer specializing in premium women's fashion brands.
- Create elegant, sophisticated, feminine, and modern interfaces.
- Prefer luxury editorial fashion aesthetics over generic ecommerce templates.
- Focus on visual hierarchy, whitespace, typography, and high-quality imagery.
- Make the shopping experience visually immersive without sacrificing usability.
- Avoid unnecessarily complicated layouts and decorative elements.

### 2. Brand Color System

The client-provided brand palette is mandatory.

Never replace or modify these original color values:

```css
:root {
  --primary: #754b4d;
  --primary-hover: #5e393b;
  --primary-contrast: #ffffff;

  --accent: #a86a65;
  --accent-hover: #925651;

  --secondary: #ab8882;
  --muted: #d8a694;

  --surface-tint: #e0cbb9;
  --surface-soft: #fcf9f7;
  --surface-card: #ffffff;

  --border: #e6d8ce;

  --text-main: #241718;
  --text-secondary: #634f4e;
  --text-subtle: #8f7978;

  --error: #b91c1c;
  --error-bg: #fef2f2;
  --error-border: #fecaca;

  --success: #15803d;
  --success-bg: #f0fdf4;
  --success-border: #bbf7d0;

  --background: #faf8f5;
  --foreground: var(--text-main);
}
```

Additional rules:
- Use plum wine for primary actions.
- Use warm ivory and neutral backgrounds for most sections.
- Use copper rose and dusty rose for subtle accents.
- Maintain sufficient text contrast.
- Do not introduce unrelated colors.
- Use existing CSS variables instead of hardcoding brand colors.

### 3. Typography

Preferred font combination:

- Cormorant Garamond: Editorial headings, collection titles, and promotional text.
- DM Sans: Navigation, body text, buttons, labels, and product information.

Rules:
- Establish a consistent typography scale.
- Use elegant and expressive headings.
- Maintain readable body text.
- Avoid excessive font weights.
- Use appropriate line heights and letter spacing.
- Follow the existing font-loading strategy.

### 4. Layout and Composition

- Use generous whitespace.
- Create clear visual hierarchy.
- Prefer editorial and asymmetrical compositions where appropriate.
- Avoid making every section look identical.
- Use consistent spacing.
- Avoid excessive rounded corners.
- Avoid heavy shadows and unnecessary borders.
- Use full-width imagery when it improves the composition.
- Maintain visual balance between text and photography.

### 5. Fashion Ecommerce Design

The website specializes in:
- Women's dresses.
- Sarees.
- Kurtis.
- Ethnic wear.
- Casual wear.
- Party wear.
- Fashion accessories.

Design should reflect Indian women's fashion while maintaining a contemporary premium boutique appearance.

### 6. Homepage Design

Where appropriate, use:
- Announcement bar.
- Premium navigation.
- Editorial hero section.
- Featured categories.
- New arrivals.
- Bestselling products.
- Saree collections.
- Fashion campaign sections.
- Brand storytelling.
- Newsletter section.
- Elegant footer.

Do not force unnecessary sections into the homepage.

### 7. Product Cards

- Give product images visual priority.
- Maintain consistent image ratios.
- Use appropriate object-fit behavior.
- Display product name and price clearly.
- Use subtle hover interactions.
- Support secondary images when available.
- Keep badges minimal.
- Make wishlist and shopping interactions intuitive.
- Avoid excessive card borders and shadows.

### 8. Product Details

- Use large product imagery.
- Create an elegant gallery.
- Maintain clear pricing hierarchy.
- Make size and color selection intuitive.
- Keep product descriptions readable.
- Make Add to Cart visually prominent.
- Organize product information logically.
- Preserve existing shopping functionality.

### 9. Responsive Design

- Design independently for desktop, tablet, and mobile.
- Do not simply shrink desktop layouts.
- Maintain typography hierarchy on smaller screens.
- Use appropriate product grid columns.
- Ensure navigation works properly on mobile.
- Maintain comfortable touch targets.
- Avoid horizontal overflow.

### 10. Accessibility

- Use semantic HTML.
- Maintain sufficient color contrast.
- Provide meaningful image alt text.
- Ensure keyboard accessibility.
- Use visible focus states.
- Do not rely only on color to communicate information.
- Respect reduced-motion preferences.

### 11. Code Quality

- Use functional components only. Never use classes.
- Follow the existing folder structure.
- Reuse existing components and utilities.
- Search before creating new components.
- Avoid duplicate styling.
- Follow existing Tailwind CSS conventions.
- Keep Server Components as the default.
- Use Client Components only when required.
- Preserve existing business logic and functionality.

### 12. Before Completing Any UI Task

1. Inspect the existing implementation.
2. Review available reusable components.
3. Verify the brand color palette.
4. Check typography and spacing consistency.
5. Verify desktop and mobile layouts.
6. Ensure existing interactions still work.
7. Check for unnecessary CSS and duplicated components.

## Final Design Principle

Every page should feel like part of the same premium women's fashion brand.

Prioritize elegance, simplicity, fashion photography, typography, whitespace, and usability.

Never sacrifice usability for visual decoration.

# GSAP Animation Development Standards

## Instructions & Rules

### 1. Animation Philosophy

- Create smooth, subtle, premium animations.
- Animations should enhance the fashion shopping experience.
- Prefer elegant transitions over exaggerated effects.
- Avoid animating every element.
- Keep animations purposeful.
- Never sacrifice usability or performance for animation.
- Avoid distracting, excessive, or unnecessarily long animations.

### 2. GSAP Usage

- Use the existing GSAP package.
- Do not install another animation library.
- Prefer GSAP timelines for coordinating multiple animations.
- Use ScrollTrigger for scroll-based animations.
- Use reusable animation utilities when appropriate.
- Keep animation logic separate from unrelated business logic.
- Follow the existing project architecture.

### 3. React and Next.js Integration

- Use GSAP only in components where browser-side animation is required.
- Keep Server Components as the default.
- Add "use client" only when necessary.
- If @gsap/react is installed, prefer its useGSAP integration.
- Otherwise, use GSAP context management and proper cleanup.
- Avoid unnecessary useEffect hooks.
- Ensure animations work correctly with React Strict Mode.
- Avoid duplicate animation initialization during re-renders.
- Scope selectors to their relevant component.

### 4. GSAP Timeline Standards

- Use timelines when multiple elements need coordinated animations.
- Use stagger for groups of elements.
- Use appropriate easing functions.
- Keep animation durations consistent.
- Avoid deeply complicated timelines.
- Use labels when they improve timeline readability.
- Avoid unnecessary nested timelines.

### 5. ScrollTrigger Standards

Use ScrollTrigger for:
- Section entrance animations.
- Editorial text reveals.
- Image reveals.
- Subtle parallax.
- Product collection animations.
- Scroll-based storytelling.

Rules:
- Use appropriate trigger elements.
- Avoid unnecessary ScrollTriggers.
- Configure start and end positions intentionally.
- Clean up ScrollTriggers when components unmount.
- Avoid pinning sections unless there is a clear design reason.
- Avoid scroll animations that interfere with natural scrolling.
- Verify behavior on mobile devices.
- Handle layout changes and refreshes appropriately.

### 6. Fashion Website Animation Patterns

#### Hero Section
- Smooth image reveals.
- Staggered heading entrance.
- Delayed CTA entrance.
- Subtle image movement.

#### Product Cards
- Image scale on hover.
- Secondary image reveal.
- Subtle product information transitions.
- Staggered viewport entrance.

#### Navigation
- Dropdown reveal.
- Mobile menu transitions.
- Header appearance transitions.
- Smooth menu closing.

#### Editorial Sections
- Image clip-path reveals.
- Text entrance animations.
- Subtle parallax.
- Scroll-based storytelling.

#### Shopping Interactions
- Add-to-cart feedback.
- Wishlist interaction.
- Cart drawer transitions.
- Quick-view transitions.

Never animate essential shopping interactions in ways that delay user actions.

### 7. Animation Performance

- Prefer transform and opacity animations.
- Avoid excessive layout-triggering properties.
- Avoid unnecessary continuous animations.
- Avoid excessive blur and filter effects.
- Keep animation complexity low on mobile.
- Avoid animating large numbers of DOM elements simultaneously.
- Avoid unnecessary will-change declarations.
- Prevent layout shifts during animation.
- Clean up all event listeners and animation instances.

### 8. Reusable Animation Utilities

- Search existing animation utilities before creating new ones.
- Reuse common animation patterns.
- Create shared animation helpers when there is clear reuse.
- Avoid duplicating identical timeline configurations.
- Keep animation configuration maintainable.
- Do not build an unnecessarily complicated animation framework.

### 9. Accessibility

- Respect prefers-reduced-motion.
- Provide appropriate reduced-motion alternatives.
- Do not hide important information behind animations.
- Avoid flashing or excessively fast transitions.
- Keep navigation and interactions accessible without animations.
- Ensure animations do not interfere with keyboard interactions.

### 10. Animation Cleanup

- Revert GSAP contexts when components unmount.
- Kill unnecessary timelines.
- Clean up ScrollTriggers.
- Avoid duplicated animations after navigation.
- Avoid memory leaks.
- Ensure route transitions do not leave stale animations behind.

### 11. Before Completing Any Animation Task

1. Verify the animation works correctly.
2. Check React lifecycle behavior.
3. Verify GSAP cleanup.
4. Check ScrollTrigger behavior.
5. Test desktop and mobile.
6. Test reduced-motion behavior.
7. Check browser console errors.
8. Verify that animation does not break existing interactions.

## Final Animation Principle

The website should feel smooth, elegant, and premium.

Use animation to guide attention, reveal fashion imagery, and improve interactions.

The goal is not to show off GSAP. The goal is to make the entire shopping experience feel effortless and sophisticated.
